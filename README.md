# 🐝Waspy - The WhatsApp Chat Analyzer🐝

For those who want to extract and plot analytics from their chats, this app is for you! ❤️‍🩹

## Features

✅ Basic analysis from messages and members of the group <br>
✅ Morphological statistics from messages (tokenization) <br>

### Comming Soon
⚙️ Plot members interaction graph <br>
⚙️ User Interface <br>

## Installation

Create an virtual environment and install packages

```bash
# create virtual environment
$ python -m venv .venv

# activate environment
$ .venv\Scripts\activate     # windows
$ source .venv/bin/activate  # linux/mac

# install packages
$ pip install -r requirements.txt
```

### External libraries

- [Spacy](https://spacy.io/)
- [Tqdm](https://tqdm.github.io/)
- [DearPyGui](https://github.com/hoffstadt/DearPyGui)

## Usage

1. Export chat with the option "Export" within your group chat settings.
2. Modify chat path in the code (temporary, we'll implement an UI)
